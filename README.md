# Partituras em uma pesquisa

<img src="assets/screenshot.gif">

## Sobre
Aplicação web que centraliza a busca de partituras em diferentes plataformas. O usuário realiza uma única pesquisa e recebe resultados de diversos sites especializados em partituras.

## Método de pesquisa
"nomeMusica + instrumento"

(Filtros adicionam automaticamente o instrumento na pesquisa. Não é necessário digitá-lo novamente.)

## Tecnologias
- Html
- Css
- JavaScript
- bcrypt
- Python
- JWT
- Flask
- serpApi
  
## Funcionalidades

- Pesquisa de partituras em múltiplos sites
- Pesquisa por instrumento
- Sistema de favoritos
- Cadastro de usuários
- Login com autenticação JWT
- Verificação de e-mail
- Criptografia de senha utilizando bcrypt

- Organização de rotas com Flask
- Tratamento de erros
- Manipulação de respostas JSON
- Deploy de aplicações web
